# Security Policy

## Scope

This repository is a curated Markdown awesome-list. It ships no runtime application and
collects no user data. The main security surface is the **external links** in `README.md`
and the small Node tooling under `scripts/`.

## Reporting a vulnerability

If you find a security issue — for example a link that now points to malicious content, or a
problem in the maintenance scripts — please report it privately:

- Use **GitHub Security Advisories** ("Report a vulnerability") on this repository, or
- Open a minimal issue **without** exploit details and request a private channel.

Please do not disclose the issue publicly until it has been addressed.

## Response targets

- Acknowledgement: within **5 business days**.
- Triage and remediation plan: within **10 business days** of acknowledgement.

## Supported versions

The `main` branch is the only supported version; fixes are applied there.
